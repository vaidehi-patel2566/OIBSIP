# To-Do Web App

## Overview
An interactive to-do list that splits work into pending and completed
tasks. Users can add, edit, complete and delete items. Tasks stay saved
in the browser with localStorage.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- localStorage

## Features
- Add Task form
- Pending and completed lists
- Mark complete / mark pending toggle
- Inline edit
- Delete from either list
- Pending and completed counts
- Timestamps for added and completed times
- Empty-state messages
- Persistence across page refreshes

## How to Run
1. Open the project folder.
2. Open `index.html` in a web browser.

## Project Structure
- index.html — App layout
- style.css — Styling
- script.js — Task logic and storage
- README.md — Project documentation
