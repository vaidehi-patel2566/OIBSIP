# Temperature Converter Website

## Overview
An interactive web tool that converts temperature values between
Celsius, Fahrenheit and Kelvin, with input validation and absolute
zero handling.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Poppins)

## Features
- Numeric temperature input
- Error message for empty or non-numeric values
- Input unit selector: Celsius, Fahrenheit, Kelvin
- Convert button
- All three converted values shown at once
- Absolute zero check with a user-friendly error
- Centre-aligned layout with clear labels

## How to Run
1. Open the project folder.
2. Open `index.html` in a web browser.

## Project Structure
- index.html — Page layout
- style.css — Styling
- script.js — Conversion and validation
- README.md — Project documentation
