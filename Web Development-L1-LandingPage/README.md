
# Nexora Digital — Landing Page

## About the Project
Nexora Digital is a responsive landing page for a fictional digital agency.
It introduces the agency, showcases services, explains the brand, and
provides a contact section.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive media queries

## Features
- Sticky navigation with section links
- Hero section with headline and call-to-action buttons
- Services cards
- About section
- Contact call-to-action
- Footer with social media links
- Responsive layout for desktop, tablet and mobile
- Smooth scrolling

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a browser.

## Project Structure
- index.html — Page structure
- style.css — Styling and responsive design
- README.md — Project documentation

## Note
This project is created for learning and internship demonstration.
The contact email and social links are placeholders.
