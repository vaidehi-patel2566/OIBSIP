# Tribute Page — Dr. A.P.J. Abdul Kalam

## Overview
A responsive tribute page dedicated to Dr. A.P.J. Abdul Kalam, scientist
and former President of India. The page includes a portrait, original
biographical writing, a timeline of achievements and a styled quote.

## Tech Stack
- HTML5
- CSS3
- Google Fonts (Playfair Display and Source Sans 3)

## Features
- Title and one-line tagline
- Prominent portrait from Wikimedia Commons
- Four original biography paragraphs
- Timeline of key achievements
- Distinct quote block
- Two section background colours
- Serif headings and sans-serif body text
- Responsive layout for desktop and mobile

## How to Run
1. Open the project folder.
2. Open `index.html` in a web browser.
3. An internet connection is required to load the Google Fonts.

## Project Structure
- index.html — Page content
- style.css — Layout and typography
- abdul-kalam.jpg — Wikimedia Commons portrait
- README.md — Project documentation
