# Personal Portfolio Website

## Overview
A responsive personal portfolio website for showcasing my background,
technical skills, projects and contact information.

## Tech Stack
- HTML5
- CSS3
- Google Fonts (Poppins)
- CSS Grid and Flexbox
- Responsive media queries

## Features
- Personal hero section and avatar placeholder
- About Me section
- Technical skills grid
- Project cards with GitHub links
- Contact section with email, GitHub and LinkedIn
- Sticky navigation
- Smooth scrolling
- Responsive desktop, tablet and mobile layouts

## Project Structure
- index.html — Website structure and content
- style.css — Styling and responsive layout
- README.md — Project documentation

## How to Run
1. Open the project folder.
2. Open index.html in a web browser.
3. An internet connection is required to load the Google Font.
