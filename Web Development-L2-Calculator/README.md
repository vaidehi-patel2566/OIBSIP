# Calculator

## Overview
A browser-based calculator for addition, subtraction, multiplication and
division. It supports operator chaining, decimal values and a clear error
state when dividing by zero.

## Tech Stack
- HTML5
- CSS3 (CSS Grid for the keypad)
- Vanilla JavaScript
- Google Fonts (Poppins)

## Features
- Display for the current value and pending expression
- Number buttons 0–9 and a decimal point
- Operators: +, −, ×, ÷
- Equals, Clear and Backspace
- Division-by-zero shows an error instead of crashing
- Sequential operations without resetting after each step
- Event listeners on buttons (no inline onclick)
- No eval() used

## How to Run
1. Open the project folder.
2. Open `index.html` in a web browser.

## Project Structure
- index.html — Calculator layout
- style.css — Styling and grid keypad
- script.js — Arithmetic logic
- README.md — Project documentation
