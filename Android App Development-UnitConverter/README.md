# Unit Converter

## Overview
An Android app that converts a numeric value between units of length, weight, and temperature. The user picks a category, a source unit, and a target unit, then converts the entered value.

## Tech Stack
- Android Studio
- Java
- XML
- Material Components

## Features
- Numeric input field
- Category selector for length, weight, and temperature
- Source and target unit dropdowns
- Unit dropdowns reset when the category changes
- Convert button
- Result shown with the target unit label
- Toast message when the input is empty or not a number

## How to Run
1. Open this folder in Android Studio.
2. Let Gradle sync finish.
3. Run the app on an emulator or a physical device.

## Project Structure
- app/src/main/java/com/oibsip/unitconverter/MainActivity.java — input, validation, and conversion
- app/src/main/res/layout/activity_main.xml — screen layout
- app/src/main/res/values — colours, strings, and theme
